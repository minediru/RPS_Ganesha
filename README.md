# 🍺 焼き鳥じゃんけん (Yakitori Janken)

焼き鳥屋の店内で、お客様がスマートフォンで楽しめる昭和レトロ風のじゃんけんミニゲームです。  
商売繁盛・福の神「ガネーシャ大将（ガネーシャ店主）」と真剣勝負し、勝つと「ドリンク1杯無料」特典画面が表示されます。

---

## 🎮 ゲーム仕様

### 1. ゲームルール
- **対戦相手**: 焼き鳥屋のガネーシャ店主（大将）
- **プレイヤーの手**: 「✊ グー」「✌️ チョキ」「🖐️ パー」から選択
- **店主の手の確率**:
  - グー: 33.3%
  - チョキ: 33.3%
  - パー: 33.4%
- **演出テンポ**: 「じゃんけん……」→「ぽん！」と短くテンポの良い演出で進行

### 2. 勝敗判定と画面
- **勝利（ジョン・ウー監督風 ド派手シネマティック演出）**:
  - **白い鳥の羽（John Woo Feathers）**: 画面いっぱいにスローモーションで舞い散り漂う美しい無数の白い鳥の羽！
  - **白鳩の飛翔**: 画面下部から悠然と羽ばたき飛び去る白い鳩のシルエット演出。
  - **シネマティック発光＆画面振動**: 勝利の瞬間に画面が一瞬白く輝く閃光フラッシュと、ズシンと響く重低音の画面シェイク（衝撃振動）。
  - **舞い踊る黄金の小判＆紙吹雪**: 商売繁盛の「万両小判」と豪華紙吹雪が乱舞。
  - **壮大なシネマティック・ブラスファンファーレ**: Web Audioによる重厚なオーケストラ風ファンファーレ＆キラキラ響くグロッケン。
  - **黄金チケット**: 「🎉 勝った！！」「ドリンク1杯無料！」の黄金チケット、回転する神仏マンダラ後光。
  - 「店員さんにこの画面を見せてください」
  - ランダム生成の簡易認証番号（例：`認証番号 #4827`）
  - 獲得日時（例：`2026年9月29日 10:37:15`）
  - ※注意書き：「本認証番号および日時は簡易表示であり、完全な不正防止機能ではありません。」
- **負け**:
  - 「💀 負け！」
  - 「今日は店主の勝ちだな」
  - 「もう一度勝負」ボタン
- **あいこ**:
  - 「🔥 あいこ！」
  - 「もう一勝負！」
  - 短い演出の後、テンポよく再戦可能

### 3. デザイン・UI
- **テーマ**: 昭和レトロな焼き鳥屋 × 小さなゲームセンター
- **キャラクター（福の神・ガネーシャ店主）**:
  - 象の頭、大きな耳、折れた牙と長い牙、黄金の宝冠と紅白ねじり鉢巻、額の三叉吉祥印（ティラク）。
  - **画面左の手**: 炭火の焦げ目と秘伝タレが光るジューシーな「ねぎま串」＆「つくね串」、立ち上る香ばしい湯気。
  - **画面右の手**: キンキンに冷えた「生ビールジョッキ」（溢れるクリーミーな泡、黄金の炭酸ビール、冷えたジョッキの結露）。
  - **衣装**: 藍色の酒場前掛け（帆前掛け：「大将」「福徳ガネーシャ」）。
- **背景演出（派手な炭火酒場エフェクト）**:
  - 立ち上る炭火の業火、黄金のマンダラ後光・旭光放射ライン、激しく舞い散る炭火の火の粉、赤ちょうちん、回転する光芒アニメーション。
- **スマートフォン最適化**:
  - 親指で押しやすい大型の3D押し込みボタン
  - 誤タップ防止のロック制御
  - PC・タブレットでも快適に動作するレスポンシブデザイン
  - Web Audio APIによるレトロな効果音（音ON/OFF機能つき・外部音声ファイル不要）

## 🚀 デプロイ (Vercel)

本リポジトリはHTML、CSS、JavaScriptのみの完全な静的Webサイト（Static Site）構成となっています。
外部API、データベース、認証サーバーは不要で、VercelやGitHub Pages、Cloudflare Pagesなどにそのまま公開可能です。

### Vercelでの公開手順
1. GitHubリポジトリにプッシュ
2. Vercelダッシュボードからリポジトリをインポート
3. Framework Presetは **Other** または **Vite** を選択
4. **Deploy** をクリック
